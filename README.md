# KR-DENT · Laboratorio Dental Digital

Sitio estático (HTML/CSS/JS) para KR-DENT: laboratorio dental especializado en CAD/CAM e impresión 3D.

Secciones: valores, quiénes somos, arancel por material, diseño digital, casos, plazos de entrega y requisitos de ingreso.

Abrir `index.html` en el navegador o publicar con GitHub Pages (rama `main`, carpeta raíz).
